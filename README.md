# 🏥 Hospital Operations & Financial Analytics Dashboard | Power BI

## 📌 Project Overview

The Hospital Operations & Financial Analytics Dashboard is an interactive Business Intelligence solution developed using Microsoft Power BI to analyze hospital performance from operational, clinical, and financial perspectives.

The dashboard enables healthcare administrators to monitor key performance indicators (KPIs), evaluate patient care, optimize hospital resources, and support data-driven decision-making.

---

# 🎯 Project Objectives

- Monitor overall hospital performance
- Analyze patient admissions and discharges
- Evaluate clinical performance
- Analyze financial performance
- Improve operational efficiency
- Monitor patient waiting time
- Analyze bed occupancy
- Support strategic healthcare decisions
